# demo

## 小遊戲

- [少做少錯：公務員的一天](https://willismax.github.io/demo/civil-servant/)：做了可能被陳情，不做也可能被陳情。
- [責任不外包：委外訓練單位承辦人的一天](https://willismax.github.io/demo/training/)：透天厝裡的招生、師資、津貼、評選、查課與就業追蹤。
- [三民路 129 號：臺中科大三民校區 3D 散步](https://willismax.github.io/demo/nutc/)：從校門口走到一中街、育才街和中友百貨，找回 6 個百年記憶。

三個遊戲都是單一 HTML 檔，直接用瀏覽器開 `civil-servant/index.html`、`training/index.html` 或 `nutc/index.html` 也能玩（`nutc` 需要連網載入 three.js）。事件改編自新聞報導過的真實案例，來源附在遊戲結局畫面。

## 教學工具

- [排序演算法 3D 實驗室](https://willismax.github.io/demo/sorting-lab/)：用立體長條動畫一步一步看泡沫、選擇、插入、希爾、合併、快速、堆積七種排序，同步亮起 Python、C、Java 程式碼中正在執行的那一行。

單一 HTML 檔，需要連網載入 three.js。網址加上 `#quick`、`#merge` 等可直接開啟指定的演算法。
