# demo

## 小遊戲

- [少做少錯：公務員的一天](https://willismax.github.io/demo/civil-servant/)：做了可能被陳情，不做也可能被陳情。
- [責任不外包：委外訓練單位承辦人的一天](https://willismax.github.io/demo/training/)：透天厝裡的招生、師資、津貼、評選、查課與就業追蹤。
- [三民路 129 號：臺中科大三民校區 3D 散步](https://willismax.github.io/demo/nutc/)：從校門口走到一中街、育才街和中友百貨，找回 6 個百年記憶。

三個遊戲都是單一 HTML 檔，直接用瀏覽器開 `civil-servant/index.html`、`training/index.html` 或 `nutc/index.html` 也能玩（`nutc` 需要連網載入 three.js）。事件改編自新聞報導過的真實案例，來源附在遊戲結局畫面。

## 同人小品

- [活俠傳結緣寵物](https://willismax.github.io/demo/mortal-pets/)：把小梅、小竹、小師妹、龍湘、夏侯蘭養在 Codex 與 Claude Code 裡，摸頭、餵食、練功、聊天累積好感。Claude Code 安裝：`/plugin install mortal-buddy --marketplace willismax/demo`，Codex 與其他安裝方式見 [mortal-pets/README.md](mortal-pets/README.md)。

## 教學工具

排序演算法、二元樹與 IP 切割的 3D 教學工具放在 [CS_Course](https://willismax.github.io/CS_Course/interactive-tools/)。原本的 `demo/sorting-lab/` 與 `demo/tree-lab/` 網址會自動轉到新位置。
